Sibilius —— P Buff 表三：战斗 / 进攻常驻
版本：ATL719 / D&D 3.5 全扩 / 架构者8阶段

============================================================
一、使用口径
============================================================

这张表只处理一件事：
【哪些合法P法术能把“西比留斯本人”变成一个24小时持续工作的攻击系统。】

与前两表分工：
- 表一：个人自保、移动、感知、反施法、身体状态。
- 表二：光环、团队常驻、阵地/旅行团队效果。
- 表三：攻击动作、攻击方式、额外攻击、重复输出、攻击穿透、近战模块。

沿用既定P规则：
1. 距离必须为“个人”或固定尺数。
2. 持续时间不能是瞬发/立即。
3. 明确“释放后结束”“下一次攻击/下一次法术耗尽”“施放后只能执行一次”的效果，不因为P而获得无限刷新。
4. 固定0尺属于固定距离，可P。
5. 全部官方3.5职业表、进阶职业表、领域表均可作为入口。
6. 高环初始化可通过古德里安架构学派 / 麦克斯韦提供的高环触发物品完成，不按13级PC财富限制。
7. [邪恶]描述符本身允许；[善良]效果不进入默认表。
8. 明确要求“调用某位神/守护神/神祇的力量、祝福、恩赐”的法术排除。
9. 西比留斯有心灵免疫；依赖[影响心灵]或精神性附魔让自己获得收益的法术，不计入有效常驻。
10. 身体变形仍沿用表一文化筛选：
    可以材料化、元素化、轻度外形变化；
    不能把“西比留斯”替换成某个明确的神祇化身、魔鬼模板或任意怪物身份。

评级：
S+++：改变整个行动/资源系统，已经接近“规则引擎”。
S++ ：构成核心战斗架构。
S   ：直接进入默认攻击栈。
A   ：明显有收益，按战斗模式开启。
B   ：合法但收益有限/与西比留斯数值不匹配。

重要：
【表三不是表二的“有多少带多少”。】
攻击型P里存在友伤、强制形态、施法封锁、目标锁定等副作用，必须分默认常驻与战术模式。

============================================================
二、A类：默认攻击核心 —— 无明显副作用，优先全天运行
============================================================

【1. 选择命运（Choose Destiny）】
入口：命运领域9环
来源：《命运种族》（Races of Destiny）
距离：个人
持续：1轮/等级
P：是

效果：
- 每次进行攻击骰、技能检定、属性检定、豁免时：
  掷两次d20，选择其中一个结果使用。

评价：
S+++。
这不是普通“+X”加值，而是对几乎所有关键d20行为提供双掷取优。
对西比留斯的意义尤其大：
- 雷霆长枪攻击；
- 刀云攻击；
- 射线/远程接触攻击；
- 关键豁免；
- UMD与关键技能。
全部同时受益。

它不依赖神祇文本，也没有[善良]描述符，因此按当前ATL规则允许。
若能取得9环初始化接口，属于第一优先级。


【2. 奥术激涌（Arcane Spellsurge）】
入口：法师/术士/吴术士7环
来源：《龙之魔法》p.64
距离：个人
持续：1轮/等级
P：是

效果：
- 标准动作奥术法术 -> 迅捷动作。
- 整轮动作奥术法术 -> 标准动作。
- 2～10轮施法时间 -> 减少1轮。
- 不能主动选择按原施法时间施放。
- 不与其他“缩短施法时间”效果叠加。

重要限制：
这并不自动等于“每轮两发标准动作法术”。
因为标准动作法术全部被压成迅捷动作，而一轮通常只有一个迅捷动作。

但对西比留斯仍然是S+++：
【迅捷动作施法 + 标准动作使用法杖/魔杖/UMD/其他非施法动作】
可以稳定并行。

这和他的“机关术士+高UMD+大量魔法物品接口”极度匹配。


【3. 猎手之眼（Hunter's Eye）】
入口：游侠2环
来源：《玩家手册II》
距离：个人
持续：1轮
P：是

效果：
- 获得偷袭能力。
- 每3个施法者等级获得+1d6偷袭。
- 若本来已有偷袭，数值叠加。

CL13时：
+4d6偷袭。

评价：
S++。
西比留斯已经长期运行【高等隐形术】。
当敌人不能看穿隐形、因此失去对西比留斯攻击的敏捷AC时，通常满足偷袭条件。

它同时作用于：
- 雷霆长枪等近战攻击；
- 刀云的远程攻击；
- 其他满足偷袭条件的带攻击骰攻击。

常规偷袭距离仍为30尺；对超远距离攻击不能自动偷袭。


【4. 魔像击（Golem Strike）】
入口：法师/术士1环
来源：《法术大全》p.106
距离：个人
持续：1轮
P：是

效果：
- 可以像对普通生物一样对构装体造成偷袭伤害。
- 仍需满足其他偷袭条件。

评价：
S。
因为【猎手之眼】把偷袭变成西比留斯的常驻输出层，构装体免疫会成为明确漏洞。
本法术直接补上“构装体”这一类。


【5. 藤蔓击（Vine Strike）】
入口：德鲁伊/游侠1环
来源：《法术大全》p.230
距离：个人
持续：1轮
P：是

效果：
- 可以对植物生物造成偷袭伤害。
- 仍需满足其他偷袭条件。

评价：
A/S。
与【魔像击】相同，是猎手之眼的目标类型扩展包。
虽然有神术焦点成分，但正文不是“神祇直接赐福”，而是与自然力量建立联系；按当前筛选口径允许。


【6. 刀云（Cloud of Knives）】
入口：牧师/法师/术士2环
来源：《玩家手册II》
距离：个人
持续：1轮/等级
P：是

效果：
- 每轮自己回合开始时，可以用【自由动作】射出一把刀。
- 射程30尺。
- 攻击加值 = 施法者等级 + 关键施法属性调整值。
- 命中：1d6 + 每3CL +1（最高+5）。
- 19-20重击。
- 视作魔法武器克服DR。

CL13：
基础伤害 = 1d6+4。

西比留斯：
- 智力25时，攻击约为 CL13 + Int7 = +20。
- 若以后装备把智力提高到31，攻击约为 +23。
- 满足偷袭条件时，可叠加【猎手之眼】的+4d6。

于是CL13、Int31、可偷袭目标：
每轮自动获得一次约【5d6+4】的自由动作攻击，
而且不占标准动作/移动动作/迅捷动作。

评价：
S++。
这是表三中最典型的“脱手攻击”：
施放一次后，整天每轮自产一发攻击。


【7. 引导射击（Guided Shot）】
入口：游侠1 / 法师1 / 术士1
来源：《法术大全》p.108
距离：个人
持续：1轮
P：是

效果：
- 远程攻击不因距离承受攻击减值。
- 忽略“非完全掩蔽”带来的AC加值。
- 忽略“非完全隐蔽”带来的失手率。
- 仍不能穿过完全掩蔽，也不能超过武器本身最大射程。

评价：
S。
对任何依赖远程攻击骰的武器/法术都属于稳定质量提升。
没有动作副作用，适合全天常驻。


【8. 寻隙（Find the Gap）】
入口：刺客/圣武士/游侠3环
来源：《法术大全》p.91
距离：个人
持续：1轮/等级
P：是

效果：
- 每轮第一次近战或远程攻击视作接触攻击。
- 忽略护甲、盾牌、天生护甲及其增强加值。
- 闪避、偏斜、幸运等仍然生效。

评价：
A/S。
对射线本来就是接触攻击，所以无收益；
对实体远程武器、刀云之外的普通攻击、未开幽魂打击的近战攻击有价值。
由于【幽魂打击】会让全部近战攻击变接触，本法术主要补“每轮第一发远程实体攻击”。


============================================================
三、B类：智力近战模块 —— 西比留斯真正合理的近战形态
============================================================

结论先写：
西比留斯不是传统“力量/BAB近战人”。
裸BAB只有+6，力量8。
因此不能照抄神术近战的【神能】模板。

真正适合他的近战武器不是普通装备，而是：
【雷霆长枪 + 幽魂打击 + 猎手之眼 + 高等隐形术 + 迅捷加速术】。


【9. 雷霆长枪（Thunderlance）】
入口：法师/术士4环
来源：《法术大全》p.220
距离：个人（部分原始索引写0尺；均为固定距离）
持续：1轮/等级（可解消）
P：是

效果：
- 生成1～20尺长的力场长枪。
- 获得20尺自然触及。
- 基础伤害3d6，重击20/x3。
- 攻击与伤害【不用力量】，改用“智力或魅力中较高的调整值”。
- 命中3环及以下力场效果时，可以额外尝试解除该力场。
- SR：无。

评价：
S+++（对西比留斯专属）。

这几乎是为西比留斯量身定制的武器：
- 力量8完全不重要；
- 智力25直接转攻击与伤害；
- 以后智力+6装备还能继续提高；
- 20尺触及；
- 力场伤害；
- 与幽魂打击直接组合。


【10. 幽魂打击（Wraithstrike）】
入口：法师/术士2环
来源：《法术大全》p.243
距离：个人
持续：1轮
P：是

效果：
- 持续期间【所有近战攻击】都按近战接触攻击结算。

评价：
S+++。
不是“第一击”，而是全部近战攻击。
所以雷霆长枪的整套全力攻击全部打接触AC。


【11. 刀刃幻舞（Bladeweave）】
入口：吟游/法师/术士2环
来源：《法术大全》p.31
距离：个人
持续：1轮/等级（可解消）
P：是

效果：
- 每轮一次：
  你成功用近战武器攻击一个目标后，
  选中其中一个被命中的目标。
- 目标意志豁免失败 -> 晕眩（dazed）1轮。
- SR适用。

评价：
S。
这不是伤害增幅，而是给雷霆长枪附上一层“每轮一次命中后晕眩检定”。
晕眩是极强控制状态。


【12. 狮子冲锋（Lion's Charge）】
入口：游侠2 / 德鲁伊3
来源：《法术大全》p.133
距离：个人
持续：1轮
P：是

效果：
- 获得猛扑（Pounce）。
- 冲锋结束后可以直接全力攻击。

评价：
A/S。
西比留斯已经有全天飞行和加速；
本法术解决的是“移动到20尺触及范围后还能把雷霆长枪全套攻击打完”。


【13. 冰斧（Ice Axe）】
入口：牧师3环
来源：《法术大全》p.118
距离：个人/0尺（版本索引差异，不影响P）
持续：1轮/等级（可解消）
P：是

效果：
- 自动视为擅长该冰斧。
- 所有攻击为近战接触攻击。
- 命中2d12冷冻伤害 + 每2CL +1（最高+10）。
- 力量调整值不加入伤害。
- BAB足够时可多次攻击。

评价：
B。
规则上很好，但不适合西比留斯：
伤害不吃力量是优点，
但攻击骰仍没有【雷霆长枪】那种“智力代替力量”的机制。
因此它是“不需要幽魂打击的备用接触武器”，不是主武器。


【14. 痛苦恐惧之刃（Blade of Pain and Fear）】
入口：刺客2 / 黑卫2 / 法师3 / 术士3 / 牧师3
来源：《法术大全》p.30
距离：0尺
持续：1轮/等级（可解消）
P：是

效果：
- 生成一柄“啃咬之牙”构成的武器。
- 近战接触攻击。
- 伤害1d6 + 每2CL +1（最高+10）。
- 命中并造成伤害后，目标意志失败则恐惧1d4轮。

评价：
B/A。
控制效果不错，但攻击属性仍不如雷霆长枪。
主要价值是针对“意志差且不免疫恐惧”的敌人。

四、C类：脱手火力 / 重复攻击引擎

【15. 闪电环（Lightning Ring）】
入口：法师/术士8环
来源：《法术大全》p.132
距离：个人
持续：1轮/2等级
P：是

效果：
- 获得电抗20。
- 每轮自己回合开始：
  所有邻接生物承受10d6电伤，反射减半。
- 同时每轮开始可以用【自由动作】分别指定两条闪电：
  每条5d6，按CL5闪电束处理；
  两条可向不同方向。
- 两条闪电的豁免DC仍按8环法术计算。

评价：
S+++，但【不是默认友军编队模式】。

原因：
- 每轮自由动作两条5d6，本质是全天自产两发攻击。
- 但邻接10d6会打所有邻接生物，不区分友军。
- 在狭窄队形、平民区、实验室内是严重事故源。

结论：
【战斗模式开；日常/团队密集模式关。】


【16. 风暴狂怒（Stormrage）】
入口：牧师8 / 德鲁伊8
来源：《法术大全》p.210
距离：个人
持续：1分钟/等级（可解消）
P：是

效果：
- 飞行40尺。
- 免疫投射物/投掷武器。
- 不受自然或魔法强风影响。
- 每轮一次，用标准动作从眼睛发射电击：
  射程100尺；
  远程接触攻击；
  1d6/2CL，最高10d6；
  无豁免；
  SR适用；
  目标大量携带金属时攻击+3。

评价：
A。
其防御部分大量与表一重叠，
真正值得写进表三的是“每轮一次稳定远程接触电击”。

与【奥术激涌】的关系：
奥术法术可用迅捷动作施放后，
标准动作仍然可以拿来发这道眼部电击。


【17. 龙息术（Dragon Breath）】
入口：法师/术士4环（《法术大全》版本）
来源：《法术大全》p.73
距离：个人
持续：1轮/等级
P：是

效果：
- 获得可重复使用的龙息。
- 每次使用为标准动作。
- 使用后等待1d4轮才能再次使用。
- 选择色彩龙时获得[邪恶]描述符：
  黑/绿酸液、蓝电、红火、白冷。
- 常规伤害为1d8/2CL，最高10d8，反射减半。

ATL筛选：
- 色彩龙版本：[邪恶]，允许。
- 金属龙版本：[善良]，不进入默认工业化清单。

评价：
A。
它不是瞬间爆发，而是一个全天携带、带冷却的AoE武器接口。


【18. 地下主宰（Undermaster）】
入口：德鲁伊/法师/术士9环
来源：《法术大全》p.227
距离：个人
持续：5轮
P：是

条件：
- 必须站在地表或地下、与大地条件相容。
- 飞在空中时不应视为正常启用。

效果：
持续期间，每轮一次，可以用标准动作把下列法术之一作为类法术能力使用：
- Earth Lock
- Earthquake
- Excavate
- Flesh to Stone
- Meld into Stone
- Move Earth
- Reverse Gravity
- Soften Earth and Stone
- Statue
- Stone Shape
- Stone Tell
- Stone to Flesh
- Transmute Mud to Rock
- Transmute Rock to Mud
- Tunnel Swallow
- Wall of Stone
- Xorn Movement
等。

评价：
S+++ / “规则引擎”。

P成24小时后，它不再只是一个buff，
而是一个【每轮免费选择一个地系/控制/塑形类法术接口】。

典型战斗用途：
- Flesh to Stone；
- Reverse Gravity；
- Wall of Stone；
- Earthquake。

典型工程用途：
- Move Earth；
- Stone Shape；
- Stone Tell；
- 泥石互转。

它不依赖神祇，且不改变西比留斯身份。
如果9环初始化接口允许，这是整张表最夸张的效果之一。


============================================================
五、D类：反击甲 —— 被近战命中就自动伤害攻击者
============================================================

这组法术的共同特点：
【不消耗西比留斯后续动作。】
敌人选择近战命中，就自己触发伤害。

它们不是传统AC，而是“攻击西比留斯的成本”。


【19. 酸液鞘（Acid Sheath）】
入口：法师/术士5环
来源：《法术大全》p.7
距离：个人
持续：1轮/等级
P：是

效果：
- 以身体/手持武器近战命中你的生物：
  自动承受2点/CL酸伤，最高30。

S/A。
CL13时，被普通近战打一下，攻击者自动吃26酸伤。

【20. 火焰护盾（Fire Shield）】
入口：法师/术士4环
来源：《玩家手册》p.230
距离：个人
持续：1轮/等级（可解消）
P：是

效果：
- 近战以身体/手持武器击中你：
  攻击者承受1d6+CL伤害，最高+15。
- 可以选择火或冷版本。
- 同时对相反能量提供显著防护。

评价：
A。
与酸液鞘是不同法术，可以构成多层反击。
至于同一人同时挂“暖盾+冷盾”两份同名法术是否分别触发，
不同桌对“同一法术多个效果”的解释存在争议；
本表默认保守处理：只计一份火焰护盾。

评价：
A。
数值不高，但：
- 环位低；
- 无动作维护；
- 与酸液鞘/火焰护盾是不同法术。
因此在“初始化资源很多”的前提下值得挂。

评价：
A。
又一层无动作反击。
音波伤害抗性相对少见。

============================================================
九、明确排除项
============================================================

【神能（Divine Power）】
虽然是经典P近战核心：
- BAB变为角色等级；
- 力量+6增强；
- 临时HP。
但正文明确：
“调用守护神/神祇（patron）的神力”。
=> 与西比留斯“无信者 + 不调用神直接恩赐”的规则冲突，排除。


【神恩（Divine Favor）】
机械上是非常廉价的攻击/武器伤害幸运加值。
但正文明确：
“调用神祇的力量与智慧”。
=> 排除。


【圣星（Holy Star）】
机械上其实极适合P：
可以在法术反转、AC+6环境加值、火焰射线之间自由切换。
但开头明确写：
“调用你的神祇之力”。
=> 排除。


【正义怒火 / Righteous Fury】
正文直接要求召唤自己的神祇力量。
=> 排除。


【优雅术 / Grace】
[善良]，且直接调用神祇力量。
=> 双重排除。


【墓穴击（Grave Strike）】
本来能把【猎手之眼】扩展到亡灵，
但是具有[善良]描述符。
=> 当前ATL默认工业化规则下排除。
因此“亡灵偷袭免疫”仍是猎手之眼体系的明确漏洞。


【腾瑟变形术（Tenser's Transformation）】
能把BAB拉到角色等级，并给大量物理加值、武器擅长。
但代价是持续期间：
【不能施法，也不能使用法术触发/法术完成型魔法物品。】
如果P成24小时，相当于把西比留斯最重要的系统整天关机。
=> 不进P表。最多作为非P的紧急纯物理模式。


【夜行者变形（Nightstalker's Transformation）】
同样会关闭施法与法术触发/完成物品。
而且其中：
- 敏捷增强与海妖恩典重复；
- 反射幸运加值还会被遗迹探索者之运覆盖。
=> 对西比留斯尤其差，排除。


【变形万物 / Shapechange】
机械强度当然极高。
但它的核心就是不断把自己替换成任意非独特生物形态并获得能力。
=> 与既定文化规则“最终仍首先是西比留斯，而不是某个怪物身份”冲突。
=> 默认排除，而不是因为强度不足。


【色彩龙化身（Aspect of the Chromatic Dragon）】
- 只能邪恶阵营施放；
- 西比留斯是混乱中立；
- 形态明确是提亚马特式多首龙神化身。
=> 阵营与文化规则双重冲突，排除。


【次级/高等炼狱变形（Infernal Transformation）】
直接获得巴特祖/魔鬼形态与类型性质。
=> 不符合“仍首先被识别为西比留斯”的身体规则。
=> 排除。


【专注颂唱（Focusing Chant）】
机械上+1攻击/技能/属性检定很诱人。
但它属于精神性附魔/强制体系。
按既有“西比留斯心灵免疫不吃这类收益”的口径，
=> 不计入有效常驻。


【施虐（Sadism）/受虐（Masochism）】
[邪恶]本身不是问题；
问题在于两者是附魔系，依赖精神性状态产生幸运加值。
西比留斯的心灵免疫会使这类增益接口失效。
=> 不计入默认表。

即使忽略这一点：
- Sadism按上一轮造成的伤害给下一轮攻击/豁免/技能幸运加值；
- Masochism按自己上一轮受到的伤害给下一轮幸运加值；
机制很强，但不符合当前心灵免疫状态。


【真确施法（True Casting）】
Duration本身就是“1 spell”：
下一发法术获得SR穿透。
=> 属于明确耗尽型效果，不能被P改成无限次。


【法术强化（Spell Enhancer）】
正文限定“本轮下一发法术”获得CL/DC提升。
=> 即使Duration写1轮，效果仍在下一发法术后完成，不形成全天无限增益。


【猎手仁慈（Hunter's Mercy）】
下一次命中自动重击，命中后效果结束。
=> 明确耗尽型，不P。


【箭雨（Arrow Storm）/刀锋风暴（Blade Storm）】
两者都不是“持续期间每轮一次”。
它们的正文结构是：
【施法后，用一个整轮动作执行一次特殊群攻。】
P延长Duration不会重复产生新的“施法后触发”。
=> 不进入P表。


【致命打击（Critical Strike）】
不同3.5来源存在版本差异；
较新版本的效果明确围绕“下一次/单次攻击”。
=> 为避免把一次性攻击效果错误扩成24小时，不列核心。

============================================================
十一、CL13西比留斯：雷霆长枪实算
============================================================

基础：
BAB +6/+1
智力25 -> 调整值+7
表一已有【迅捷加速术】：
- 攻击+1
- 全力攻击多一次最高BAB攻击

雷霆长枪：
用Int替Str进行攻击和伤害。

不买智力装备：
攻击：
+6 BAB +7 Int +1 Haste = +14
全力攻击约：
+14 / +14 / +9
并且【幽魂打击】使三次全部攻击接触AC。

若以后买智力+6增强装备：
智力25 -> 31
Int调整值 +10

攻击：
+6 BAB +10 Int +1 Haste = +17
全力攻击：
+17 / +17 / +12
全部攻击接触AC。

CL13【猎手之眼】：
+4d6偷袭。

因此，满足偷袭条件时，
Int31状态的一次雷霆长枪命中约为：
3d6（长枪） + 10（Int） + 4d6（偷袭）
= 7d6+10。

三击全中：
21d6+30
平均约103.5点伤害/轮。

这还没有计算：
- 刀云的自由动作额外攻击；
- 刀刃幻舞每轮一次晕眩检定；
- 选择命运的攻击骰双掷取优；
- 任何标准/迅捷动作法术输出；
- 闪电环等额外脱手火力。

因此：
【第三表真正把西比留斯从“一个有大量防御P的施法者”
变成了“全天运行的多通道攻击系统”。】

============================================================
十二、设计结论
============================================================

1. 西比留斯不应该通过【神能】把自己伪装成传统满BAB战士。
   那不仅与无信者设定冲突，也浪费他的智力与机关术士接口。

2. 他的物理攻击正确路线是：
   【雷霆长枪把智力变成攻击/伤害】
   +【幽魂打击把全部近战改成接触攻击】
   +【猎手之眼把CL变成偷袭骰】
   +【高等隐形术制造偷袭条件】
   +【迅捷加速术/狮子冲锋提高攻击次数和移动后输出】。

3. 他的动作经济正确路线是：
   【奥术激涌把标准动作奥术法术压成迅捷】
   +【刀云每轮自由动作攻击】
   +【标准动作保留给魔法物品、风暴狂怒、其他接口】。

4. 高环P中真正需要警惕的是：
   【选择命运】【地下主宰】【闪电环】。
   它们不是普通数值buff，而是在改变骰子系统、法术资源系统或每轮动作资源。
   如果ATL世界允许工业化高环初始化，这三项会显著抬高西比留斯的战斗层级。

5. 反击甲四件套：
   【酸液鞘 + 火焰护盾 + 死亡护甲 + 伤害低语】
   不消耗后续动作，与表一防御层形成“打不中/打中也付出代价”的双层结构。

6. 当前明确漏洞：
   - 亡灵：墓穴击因为[善良]被排除，猎手之眼不能自动绕过亡灵偷袭免疫。
   - 看穿隐形/免疫偷袭的敌人：猎手之眼收益下降。
   - 反魔/解除：第三表越强，越需要保护P栈不被整体解除。
   - 友军密集：闪电环、刀刃之环、太阳之躯不能无脑开。
